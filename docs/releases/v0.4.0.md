# InvestorMate v0.4.0

**Release date:** 2026-05-30

This release is all about **a rock-solid foundation**: a pluggable data layer,
a new AI provider, and a deep round of reliability, security, and tooling
hardening — without breaking the existing API.

> Upgrade: `pip install -U investormate`

---

## ✨ Highlights

### 🔌 Pluggable data sources

All market and fundamental data now flows through a `DataProvider` interface.
The default `YFinanceProvider` behaves exactly as before (same caching and rate
limiting), but you can now swap the data source process-wide — for an alternate
API, recorded fixtures, or deterministic tests — without touching any call site.

```python
from investormate import DataProvider, set_data_provider, reset_data_provider

class MyProvider(DataProvider):
    def get_info(self, ticker):
        return {"symbol": ticker, "currentPrice": 100.0}
    # ... or subclass YFinanceProvider and override just a method or two

set_data_provider(MyProvider())   # Stock, Portfolio, Screener, Market, ... all use it
reset_data_provider()             # back to yfinance
```

See [docs/data_providers.md](../data_providers.md).

### 🤖 OpenRouter support

One API key, hundreds of models (OpenAI, Anthropic, Google, Meta, Mistral, …)
via OpenRouter's OpenAI-compatible gateway — no new dependency.

```python
from investormate import Investor

investor = Investor(
    openrouter_api_key="sk-or-...",
    openrouter_model="anthropic/claude-3.5-sonnet",  # optional; defaults to openai/gpt-4o
)
result = investor.ask("AAPL", "Is Apple undervalued?", provider="openrouter")
```

See [docs/ai_providers.md](../ai_providers.md).

### 🧠 Smarter, configurable AI providers

- `temperature`, `max_tokens`, `timeout`, `max_retries`, and `retry_backoff` are
  now configurable on every provider.
- Automatic **exponential-backoff retries** on transient errors (rate limits,
  timeouts, connection failures).
- `Investor.batch_analyze()` and `Investor.compare()` now run **concurrently**
  (order-preserving), for faster multi-stock workflows.

### 🔒 Security & reliability

- **SSRF protection** for document URL fetching (`Investor.analyze_document`):
  non-HTTP(S) schemes and private/loopback/link-local/metadata addresses are
  refused (`investormate.utils.net`).
- **Bounded cache** — the in-memory TTL cache now enforces a `maxsize` (default
  2048) with LRU eviction to bound memory in long-running processes.
- **Centralized logging** (`investormate.utils.logging`) with a `NullHandler`:
  the library is silent by default and fully controllable by your app — no more
  stray `print()` calls.

### 🧰 Developer experience

- Shipped `py.typed` (PEP 561) — downstream users now get InvestorMate's type
  hints.
- Pinned `black==24.10.0`, added a `mypy` config + CI step, a `pre-commit`
  config, and a 60% coverage floor in CI.
- Development status promoted to **Beta**.

---

## 🔁 Changed

- All data access is routed through the active `DataProvider`.
- Version is now single-sourced from `investormate.version` (no more drift
  between `version.py` and packaging metadata).
- `data/fetchers.py` de-duplicated via shared helpers (behavior unchanged).

## 🐛 Fixed

- Removed dead/duplicate prompt construction in `Investor.ask()` and
  `Investor.analyze_document()`.

---

## ⬆️ Upgrade notes

**Fully backwards compatible** — no public API was removed or renamed.

- If you mock data access in your own tests, the cleanest seam is now the
  provider, e.g. `@patch("investormate.data.providers.YFinanceProvider.get_info")`.
- To silence or capture library logs, configure the `"investormate"` logger.
